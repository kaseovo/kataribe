# Demo video

Not yet recorded. Screen capture (QuickTime/OBS) of a real session + the family view, no actors, narrated afterward. Recorded during the Japanese review on Oct 14–15: the steps are in [japanese-review.md](japanese-review.md).

## Shot list

1. **Kiosk, session start** — the tablet web app, a real conversation beginning.
2. **A few exchanges** — enough to show the interviewer listening, asking one thing at a time, in Japanese.
3. **Session ends** — cut, no need to show the full length.
4. **Family view** — the new story that came out of the session, linked back to the audio.
5. *(optional)* **A family question** — one submitted from the family page, and the interviewer opening the next session with it.

## Narration notes

- Explain the loop while it plays, not before: session → story → family → next question.
- Name what's real: this is an actual conversation with the product, not a mockup.
- Keep it to 2-3 minutes.
